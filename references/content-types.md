# 内容形态与进度模型

内容形态拆成两个互不替代的维度：

- **结构**：`线性` / `合集`
- **话语类型**：`虚构` / `非虚构` / `混合`

结构决定怎样记录进度和隔离阅读单元；书级话语类型描述正文的默认话语，单元级话语类型决定具体目标单元使用哪套讨论与证据方法。前后材料不继承正文类型；已确认的单元类型可覆盖书级默认值。conversation mode 仍只决定这一轮怎么聊，不落盘。

常见组合：

| 可读名称 | 结构 | 话语类型 |
|---|---|---|
| 小说、线性叙事 | 线性 | 虚构 |
| 短篇小说集 | 合集 | 虚构 |
| 线性非虚构、传记、回忆录 | 线性 | 非虚构 |
| 散文集、评论集、演讲集 | 合集 | 非虚构 |
| 混合文集、跨体裁选集 | 合集 | 混合 |

不要为了判定组合而搜索未读文本。可用读者自报、版权页/出版方等范围安全的书目资料；仍不清楚就保守写 `未确认`，等真实阅读状态变化时再补。

## 旧档兼容

旧 `book.md` 的 `内容形态：小说 / 短篇集 / 非虚构 / 叙事性非虚构` 继续有效：

- `小说` 可按 `线性 + 虚构` 使用。
- `短篇集` 可按 `合集 + 虚构` 使用。
- `叙事性非虚构` 可按 `线性 + 非虚构` 使用，除非读者明确它是合集。
- `非虚构` 至少确定话语类型为非虚构；结构先看现有进度：有 `当前篇目` / `篇目状态` 就按合集，有 `当前位置` / `已覆盖部分` 就按线性；都没有时结构写 `未确认`；只有当结构真实影响当前回答时问一句，不为分类而翻书。

读取优先级是：**本轮读者的明确纠正** → 已确认的新字段 → 旧 `内容形态` 与无冲突的现有进度字段。新字段只有可靠确认后才写非 `未确认` 值，因此跨会话把任何合法的非 `未确认` 新值视为已确认；`未确认` 视为缺失。新字段与旧 fallback 冲突时使用新字段；只有重复的新字段互相冲突，或多个同优先级 legacy 进度信号互相冲突时，才问一个范围问题，在确认前不访问电子本；不要用未读文本补分类。

不批量迁移、不整份重写。只有读者报告新进度、内容形态得到可靠确认或本来就要更新 `book.md` 时，才补 `结构` / `话语类型`；原 `内容形态` 可保留作可读名称。

## 稳定单元标识

`unit_id` 只由单元类别与版本内定位组成，不含显示标题：`<类别>-<定位>`。类别使用 `正文 / 序 / 前言 / 导读 / 编者按 / 后记 / 附录`；定位使用该版本内的两位顺序号，或不会重名的责任角色，必要时再加顺序号。例如 `正文-03 · 无题`、`前言-作者 · 前言`、`前言-作者-02 · 再版前言`、`附录-02 · 年表`。正文标题 A 不写进 ID，因此统一使用 `正文-01`，不使用 `正文-01-A`。

ID 以当前版本的物理顺序/角色为基准，只在该 source identity 内稳定。`progress.md` 必须以规范化版本键、本体路径与本地 SHA-256 的组合，把活动单元状态、锚点和整套权限绑定到精确来源。版本、路径或指纹变化时，先把绑定设为 `未确认`，冻结旧活动表并暂停所有旧权限；再确认旧 ID 到新边界的映射。映射未确认前不读取内容；确认后只迁移唯一对应的状态，唯一对应的 `strict` 可保留，任何 `open` 都须重新授权。宿主可在安全提取器内部使用可信映射；映射未知时，只能先由仅元数据边界定位器把逻辑 ID/锚点换成本轮不透明 `scope_handle + confidence`。模型不得接收 raw member ID/path、TOC 标题、其他单元边界或 prose；歧义时不签发句柄、不读取内容。裸显示名、目录猜测或模型记忆不能充当权限键。

## 所有内容形态：前后材料

序、前言、导读、编者按、后记、附录等是独立阅读单元。无论正文是线性还是合集，都先按读者实际覆盖的单元守边界。

- 读者只在前言中时，正文仍全部未读；前言提到某篇、某章、人物、地点或意象，不会开放对应正文。
- 当前单元只表示读者此刻所在位置；本轮问题点名的**目标单元**可不同。每个目标单元分别按其已读锚点、读完状态或明确 `open` 权限定义允许语料；整本电子书可用不改变这个范围。
- 未读单元的地点、时代、意象、象征、结构、相互关系、案例、论点与结论都可能改变预期，不能当作无剧透元数据。
- 内容形态尚未确认时，先保守使用当前前后材料边界，不要为了分类而搜索正文。

## 线性结构

- 进度：章/节 + 场景、论证、案例或段落锚点。
- 用户只给“第十章”时，保守理解为刚进入第十章；只使用前九章，顺手问清章内位置。
- 多时间层仍是一个阅读锚点：记录读者实际读到的文本位置，不把故事时间当阅读进度。
- 非虚构还要记录当前主题与已覆盖范围，不能只用百分比。
- 线性正文的书级话语类型是默认值；前言、后记或嵌入式单元另有已确认类型时，按该目标单元类型路由。

## 合集结构

### 状态

`progress.md` 按阅读单元记录：

- 当前单元的 `unit_id`（只含类别与版本内定位；正文篇目或前后材料）
- 独立的显示名（只供对话，不属于 `unit_id`）
- 单元内锚点
- 各单元：未读 / 在读 / 读完 / 跳过

稳定标识用于区分重名篇目、多个「前言」或多个「附录」，例如 `正文-03 · 无题`、`前言-作者 · 前言`、`附录-02 · 年表`。显示名只供对话使用，不能单独作为权限键。身份仍有歧义时先问清；未澄清前不授予 `open`、不访问电子本。已确认的稳定单元话语类型写在 `book.md`，不把分类表放进读者进度。

允许乱序。读者跳到 B，只更新 B；A 与其他单元不变。未列出的篇目和前后材料按未读处理；`跳过` 只表示阅读选择，不等于读完或获得内容权限。不得根据目录位置、前言提名或相似主题推定已读。

### 单元边界与权限

- 每个正文篇目和每份前后材料都有独立边界。
- 读完 A 只开放 A，不开放 B、后记或整本；读者当前在 B 时仍可讨论已完成的 A。部分读过的非当前单元只开放其已记录锚点。比较多个单元时，对每个目标单元分别验证权限。
- 局部 `open` 只开放读者点名的范围：一个问题不落盘；明确开放整个单元时只记录该稳定单元标识的 `open`。开放一篇不开放其他篇，也不开放 `sealed.md`。权限不改变阅读状态；最新的明确权限指令更新当前状态，较窄的 `strict` 可遮蔽较早的整本 `open`，但本轮更晚给出的单问题授权只为这一问临时越过旧 `strict`，回答后仍保留它。
- 连作、共享人物、互相照应或主题组：在 `book.md` 只记范围安全的关系类型，不记未读照应内容；回答仍只使用明确读过或明确开放的单元。
- 不说“下一篇会解释”“这个人还会出现”“后记会收束”等跨单元元剧透。
- 单篇读完可轻量 debrief，但整本仍在读，不打开整本 `sealed.md`。

### 目标单元的方法

合集的结构规则统一，但本轮目标单元的话语类型决定方法：

- **虚构单元**：使用虚构的情节、人物、形式和剧透边界；剧情梳理不得把目录顺序误当事件因果。
- **非虚构单元**：使用下文的主张 / 书内证据 / 外部事实 / 读者判断分层；不得把相邻篇目的论点拿来补目标篇。
- **混合单元**：按本轮问题涉及的已授权片段与证据类型路由；不能把同一单元未授权部分带入。
- **未知单元**：类型可由读者自报或范围安全的书目资料确认；未知时保守回答，并在确实影响答案时问一句，不搜索未读单元来分类。

## 整本完成

单元状态不能推出整本状态，因为未列单元默认未读。只有读者明确表示“整本读完”（不是只指正文或若干单元）时，才写 `阅读状态：读完`；还必须没有仍有效的单元 `strict`，才允许打开 `sealed.md`。若读者只说“正文读完了”，正文可记完成，但未读前后材料仍独立封闭，整本状态不得自动改为 `读完`。

## 非虚构话语

### 即时意图路由

非虚构不默认走 plot：

| 当前需求 | 推荐主 mode / 方法 |
|---|---|
| 概念是什么意思 | interpretation：定义、边界、例子、反例 |
| 作者怎么推出结论 | interpretation：前提 → 推理 → 结论 |
| 证据够不够 | evaluation：证据类型 → 强度 → 缺口 → 判断 |
| 全章或当前篇怎么组织 | aesthetics 或 evaluation：形式/结构 → 效果 → 代价 |
| 能不能用到现实 | interpretation + evaluation：迁移条件 → 限制 → 可行动结论 |
| 读得烦、震动、被冒犯 | emotion 或 companionship |

旧的 difficulty/context/tracking/momentum/medium 模块仍可叠加，它们负责诊断障碍，不是 conversation mode。

### 证据纪律

涉及目标非虚构单元的主张时明确分层：

1. **作者主张**：作者声称什么；
2. **书内证据**：作者在当前已读单元里拿什么支持；
3. **外部事实**：独立来源能否证实；
4. **读者/助手判断**：基于前述信息的评价。

书中引用不自动成为外部验证。无法查到独立来源时，只能说“目标篇中这样引用，外部真实性尚未核实”。不要编研究、数据或出处，也不要借未读篇目的补充材料证明目标篇。

### 剧透边界

- 论述型非虚构：默认不提前总结未读单元或未读部分的论点、案例或结论，除非读者明确开放。
- 传记、回忆录、调查、历史叙事：与小说一样守事件与元剧透边界，即使结局是公开历史事实。
- 用户问整本公开主旨时，可给出版方级别的无剧透概述；不能顺势披露未读案例、转折或结论。
- `open` 必须来自用户明确授权；“这是非虚构”不是自动开放理由。
