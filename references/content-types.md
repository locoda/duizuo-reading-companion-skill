# 内容形态与进度模型

内容形态决定如何读进度与守边界；conversation mode 决定这一轮怎么聊。二者互不替代。

## 小说与线性叙事

- 进度：章/节 + 场景、人物行动或段落锚点。
- 用户只给“第十章”时，保守理解为刚进入第十章；只使用前九章，顺手问清章内位置。
- 多时间层仍是一个阅读锚点：记录读者实际读到的文本位置，不把故事时间当阅读进度。

## 短篇集

### 状态

`progress.md` 记录：

- 当前篇目
- 当前篇内锚点
- 各篇：未读 / 在读 / 读完 / 跳过

允许乱序。用户跳到 B，不自动改变 A。未被明确标记的篇目按未读处理。

### 剧透边界

- 独立短篇：每篇有自己的边界。读完 A 只开放 A，不开放 B。
- 连作、共享人物或互相照应：在 `book.md` 只记“有关联”，不记照应内容；回答仍只使用明确读过的篇目和篇内范围。
- 不说“下一篇会解释”“这个人还会出现”等跨篇元剧透。
- 单篇读完可做轻量 debrief，但不把整本标为读完，也不打开整本 `sealed.md`。

### Mode

六个 conversation modes 均可按当前篇目使用。剧情梳理不得把合集目录顺序误当作事件因果，也不得借已读篇目的解释越过未读篇目。

## 非虚构

### 状态

`progress.md` 记录：

- 当前位置：章 / 节
- 当前主题：概念、论证或案例
- 已覆盖部分
- 待澄清问题

不要只用百分比；“读到第三章”不说明读者处理了哪个论证。

### 即时意图路由

非虚构不默认走 plot：

| 当前需求 | 推荐主 mode / 方法 |
|---|---|
| 概念是什么意思 | interpretation：定义、边界、例子、反例 |
| 作者怎么推出结论 | interpretation：前提 → 推理 → 结论 |
| 证据够不够 | evaluation：证据类型 → 强度 → 缺口 → 判断 |
| 全章怎么组织 | aesthetics 或 evaluation：形式/结构 → 效果 → 代价 |
| 能不能用到现实 | interpretation + evaluation：迁移条件 → 限制 → 可行动结论 |
| 读得烦、震动、被冒犯 | emotion 或 companionship |

旧的 difficulty/context/tracking/momentum/medium 模块仍可叠加，它们负责诊断障碍，不是 conversation mode。

### 证据纪律

涉及作者主张时明确分层：

1. **作者主张**：作者声称什么；
2. **书内证据**：作者在书里拿什么支持；
3. **外部事实**：独立来源能否证实；
4. **读者/助手判断**：基于前述信息的评价。

书中引用不自动成为外部验证。无法查到独立来源时，只能说“书中这样引用，外部真实性尚未核实”。不要编研究、数据或出处。

### 剧透边界

- 论述型非虚构：默认不提前总结尚未读章节的论点或结论，除非读者明确要求。
- 传记、回忆录、调查、历史叙事：与小说一样守事件与元剧透边界，即使结局是公开历史事实。
- 用户问整本公开主旨时，可给出版方级别的无剧透概述；不能顺势披露后续案例、转折或结论。
- `open` 必须来自用户明确授权；“这是非虚构”不是自动开放理由。
