# 剧透与文本证据

## 先判问题，再选来源

1. 把读者当下的话压缩成最小可回答问题。
2. 判断答案是否真的需要书本文本。
3. 文化、历史、概念、语言、地理等外部语境问题，使用相应外部来源；除非读者明确问书内用法，否则不打开或搜索电子本。
4. 书本文本只是可选证据源。它已存在不等于有权限读取，也不要求把外部问题扩展成文本分析。
5. 必要歧义会改变答案时，只问一个简短澄清问题；不得从未读正文反推读者指什么。

例如，读者在前言看到「鸡蛋花」后问「鸡蛋花是不是在南方地区有什么特殊含义？」，最小问题是外部文化语境；应澄清必要的地域范围并查外部来源，不读取电子本，也不追踪鸡蛋花在未读篇目中的分布。只有「这本书为什么在这里写鸡蛋花？」才是书内用法问题。

## 书内问题先判边界

1. 读 `book.md` 的内容形态，并读 `progress.md` 的当前进度。
2. 本轮有新进度则采用；只有旧锚点时把它当安全下界。
3. 判断本轮权限：`strict` / 用户请求的 `structural` / 明确 `open`。
4. 先确定允许语料，再决定哪些材料能进入上下文。
5. 在任何电子本工具调用前先确定允许语料。已有可靠成员映射时，第一个内容承载调用必须在参数中显式指定阅读单元、锚点与成员范围，并把范围切片输出到 `/tmp`；后续搜索只能以该切片为输入。只有逻辑锚点、尚不知道 EPUB 内部成员时，可先做一次**仅元数据边界定位**：工具以当前阅读单元与锚点为输入，可在内部解析 `container.xml`、OPF manifest/spine、NCX 及 OPF 标记的 nav 导航资源，但不得打开 spine 中的 XHTML 正文资源；模型侧只接收解析器签发的本轮临时不透明范围句柄与置信度，不接收原始 member ID、文件名、路径、目录标题、其他单元或正文。随后第一个内容承载调用必须携带阅读单元、锚点与该句柄，并只在 `/tmp` 生成已读范围切片；定位不唯一就不读取内容。允许语料、句柄与定位结果都是本轮临时核查状态，不新增持久字段或文件。

### 前后材料是独立阅读单元

序、前言、导读、编者按、后记、附录等各自构成独立边界，不因位于正文前后而自动开放正文或整本。

- 读者只读到前言时，允许语料只有前言中已覆盖的部分。
- 前言提到某篇散文、短篇、章节、人物、地点或意象，不会开放被提到的正文。
- 后记可能概括全书，也不能因名为「后记」而当作安全书目材料；读者没有读到就不加载。
- 内容形态尚未确认时也执行上述边界，不把不确定性转化为全文搜索许可。

## 陈述类型

| 陈述 | 要求 |
|---|---|
| 书目事实 | 可回答；详细或易变事实需可靠来源 |
| 直接引语 | 必须有允许范围内的原文或用户贴出的片段 |
| 具体书内事实 | 情节、顺序、地点、时代、人物、意象、结构、篇目关系、例子、论点与结论都受进度边界约束；原文可作确定回答，只有二手来源时必须归因并标明未由原文核实 |
| 解释与评价 | 必须标明为推断/判断，并给已读范围内的原文或带来源的二手证据 |

非虚构另分作者主张、书内证据、外部事实、读者判断，见 `content-types.md`。

## 有电子本

- 电子本只提供证据能力，不提供权限，也不扩大当前阅读单元。
- 只有最小问题确实需要书内证据时才访问电子本。
- 已有可靠成员映射时，第一个内容承载调用必须显式携带当前阅读单元、锚点与成员范围，并把范围切片写入 `/tmp`；搜索只能针对该切片。
- 未知文件成员时，只允许先调用仅元数据边界定位器；它可以内部解析 `container.xml`、OPF manifest/spine、NCX 及 OPF 标记的 nav 导航资源，但除该导航资源外不得打开 spine 中的 XHTML 正文资源。模型侧只接收解析器签发的本轮临时不透明范围句柄与置信度，不接收原始 member ID、文件名、路径、目录标题、其他单元或正文；随后第一个内容承载调用必须携带阅读单元、锚点与该句柄，并只在 `/tmp` 生成已读范围切片。定位不唯一时停止，不读取内容。
- 不得先把整本目录送入上下文、建立全文索引、读取或搜索整本后再过滤；这些结果进入上下文时泄露已经发生。
- 无法确认截断边界或无法安全截断时，不搜索电子本；转用范围安全的外部来源、用户已贴片段或核查路径。
- 回答具体情节或引语时给出可定位的文本依据。
- 截断范围里找不到，只能说“你读到的部分里没有/无法确认”；不准用模型记忆补后文。
- 没有可靠锚点就不检索，先问位置。

## 未接入电子本

先自然问一次读者手上是否有整本可提供，不用固定话术，也不要直接默认只有“贴一段”这一条路。

读者确认没有或不便提供时：

- 先按当前问题找公开二手来源：出版方/图书馆简介、可靠书评、作者访谈等。
- `strict` 下只加载不会明显越过当前进度的来源；全书梗概、结局解析和覆盖未读内容的评论不得进入上下文。
- 用到的二手来源写进 `book.md`，包括标题、发布者/作者、URL、日期和核查限制。
- 回答时明确归因，如“出版方简介写道”“某篇书评将其概括为”；不能把二手描述说成“书里写了”。
- 二手来源可以补背景和给暂定解释，但不能证明直接引语，也不能消除具体情节或事件顺序上的不确定性。
- 能从用户贴出的片段判断时，只依据该片段作答；片段不足就说明缺什么。
- 没有合适的二手来源或片段时，给核查路径：去哪个已读章节/场景，看谁在说、是否有第三方证实、原文用了什么措辞。
- 整本、片段和二手来源都是可选路径；读者拒绝后不重复追问。

## 权限

### strict（默认）

允许：已读范围、书目事实、不改变未来预期的语境与识别方法。

禁止：未读事件、未来人物关系、结局、反转、尚未读到的地点/时代/意象/象征/结构/篇目关系/论点/案例/结论，以及任何会改变阅读预期的形式前瞻。不能因为信息「只是地理」「只是结构」或没有事件，就把它当作无剧透。

### structural

读者明确想谈结构时，可讨论不泄露事件的结构安排。时间线合流、叙述者可靠性、跨篇照应等如果会暴露未读内容，仍须压住。

### open

用户明确允许后，可越过进度。区分：

- “这个问题直接告诉我”＝只开放这个问题；
- “这本都可以剧透”＝整本覆盖，可写入 `progress.md` 并允许打开 `sealed.md`。

## `sealed.md`

- 读中完全不读取，不按锚点或 reader-signal 提前解封。
- 写入只追加，写后不回读。
- 不告诉读者“有东西先不说”；封存存在本身可能是元剧透。
- 仅整本读完或整本明确 `open` 后可打开。
- 打开后也按当前话题自然归还相关观察，不机械倾倒全部内容。

## 元剧透检查

发送前删掉任何会改变未读预期的句子，包括：

- “后面有反转 / 会解释 / 还会出现”
- “结局很惨 / 很圆满”
- “熬过这段就好 / 后面节奏会快”
- “这种写法后面会更密 / 更难”
- 对未读篇目、章节、地点、时代、意象、象征、结构、人物关系、案例或论证终点的暗示
- 以「只是地理/结构」「没有具体事件」为由提前确认未读内容

拿不准时，先问用户是否愿意开放对应范围；不要用“我先不说”制造暗示。
