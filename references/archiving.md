# L0 建档细则

`SKILL.md` 的 L0 只留判定：什么时候建档、建到什么程度、哪几步不可跳。本文件是执行细则——采集收什么、本体怎么接、确认清单怎么摆、没有文件能力时怎么办。

**建档中随时触发的纪律仍以 `SKILL.md` 的 L1 为准**，本文件不覆盖它。

---

## 定书

档案的目标状态是四项齐全：**书名、作者、版本或译本、媒介**。

版本与译本不是细节：删节本少掉的章会让锚点对不上；不同译本人名译法不同，tracking 会认错人；有声书的章节切分常与纸书不一致。所以它们最终必须补齐——**只是不该挡在第一个回答前面**。

版本或译本**不进目录名**，记进 `book.md`（见 `storage.md`）。

---

## 采集

目标是「这本书怎么读」，不是「这本书讲什么」。

- **收**：叙事结构 / 语言难度 / 语境与典故 / 形态（篇幅、章节长短、有无附录家谱地图）/ 最可能掉线的位置
- **不收**：情节梗概、人物结局、事件走向——这些一旦进档，就是一颗定时剧透弹

采集时撞上剧透（书评、维基梗概、豆瓣热评）→ 走 L1 剧透线：读到即咽下，**不写入 `book.md`**，措辞不泄露倾向。

**采集的产物是原料**，按小节填进 `book.md`。把原料组织成给读者看的**抓手清单**是 prep 的事——两者不重复做：采集只管收全，prep 只管选和排。

---

## 本体接入

**怎么问**：一句话，答不上来就过。

```
有电子本吗？epub 或 txt 都行，给我个路径。没有也不影响，我照常陪你读。
```

**不得阻塞。** 不摆清单、不停回合、不因为读者没有电子本就少交付任何一样东西。读者说「没有」「懒得弄」「回头再说」，直接往下走，之后也不反复追。

**接进来之后**：

1. **本体不进档、不复制。** `progress.md` 只记一行路径，正文留在读者自己的工作区。（路径是读者痕迹，所以记在 `progress.md` 不记在 `book.md`——`book.md` 要保持可分享。）
2. 切出**骨架**（章号 + 起止位置）写进 `index.md`。骨架**不含章节标题**——标题会剧透（「第十七章 葬礼」）。
3. 骨架之外的索引内容（章节标题、每章首句、专名首次出现）**只做到锚点为止**，读者推进时增量补。

**切骨架时不得通读全文。** 用宿主的分割或检索能力按章节标记切，只取位置，不把正文读进上下文。做不到就**不建骨架**，只留路径——用到哪一章现截哪一章，一样能用。

---

## 确认检查点

**何时做**：完整建档（prep 入口，或他人书档译本不符需重采时）落盘前必做。assist / debrief 入口只补了书名和锚点时不必走完整确认，等版本与媒介补齐后再摆一次。

把定书与采集的结果摆出来让读者纠正，纠正完再落盘：

```
我认的是这本，你核一下：
《书名》· 作者 · <版本/译本> · 你在<读 / 听 / 混着>
我采到的：<结构一句话> / <难点一句话> / <形态一句话>
有不对的说一声，我改完再存。
```

**摆完就结束回合，等读者回话。** 同一回合里摆完清单又接着落盘、接着交付，那不是检查点，是通知——读者根本没机会纠正。

读者下一条是纠正 → 改完重新摆一次。下一条不是纠正（换话题、说「差不多」、说「继续」）→ 视为通过，落盘，再往下走。

没有这一步，认错书或认错译本会静默污染全程。

---

## 复核锚点

读 `progress.md` 的锚点，然后问：

```
上次你在<锚点>，之后又读了吗？
```

**必须问，不得直接用存档值。** 存的是「上次谈话时你在哪」，不是「你现在在哪」——读者会在这个 skill 不在场的时候继续读。这两者之间隔着一条剧透线。

**锚点确认之后，顺带扫一遍封存队列**（`progress.md` 的「封存队列」小节，只有解封条件、不含观察内容）：新锚点让哪几条到期了？到期的按 id 去 `sealed.md` **定点取那一条**归还，其余不动。没有到期的，`sealed.md` 这一轮完全不打开。

归还的措辞是「你现在读到这儿了，有件事可以说了」，不是「我之前一直没告诉你」——后者会让读者觉得被瞒了一路。

---

## 降级：宿主没有文件读写能力

不建档，每次会话重问必问项，并**明说**「我这次记不住，下次你得再讲一遍」。不假装记得。

本体与索引同样失效——没有文件能力就读不了电子本，直接落到 L1 §1 的第三态（核查路径）。读者当场贴回的段落仍算临时本体，在本次会话内有效。
