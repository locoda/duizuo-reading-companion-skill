# L3 模块规格

`SKILL.md` 的分诊表给出「什么信号 → 哪个模块 → 哪条硬约束」。本文件是每个模块的完整规格：判定要点、做什么、交付物。

分诊定下模块后再读本文件对应小节。**硬约束在 `SKILL.md` 里已有一行摘要，本文件展开的是方法，不是新的纪律。**

---

### difficulty

- **判定**：难在句法、难在概念、还是难在这段本来就写得模糊（实验文本经常是第三种）。三者先分清，不要默认是读者能力问题。
- **做什么**：给这一段的脚手架——先说这段在做什么事，再讲怎么做的。**不要先讲手法后讲内容**，读者需要的是先站稳。
- **交付物**：本段的一句话功能定位 + 2–3 个可复用的读法。
- **出口**：若难度来自作者的刻意含混，直说，读者不必解出唯一答案。

### context

- **判定**：缺的是事实性背景（历史、宗教、地理）还是互文（典故、致敬、戏仿）。
- **做什么**：只补当前进度需要的部分，**不要把背景一次讲完**——背景讲全常常等于剧透。
- **交付物**：一段背景 + 它在这本书里对应哪个具体细节。
- **备注**：这是性价比最高的模块——成本低，几乎不触碰剧透线。

### tracking

- **判定**：先定位再回答。用**内容锚点**（场景、谁在场、在做什么），不用页码或百分比。
- **做什么**：确认章节与所在线索 → 排查重播/跳读（用户往往不自知）→ 更新 `progress.md` 的锚点。
- **交付物**：「你在第 N 章，X 线上」+ 从哪一句重新上车。
- **硬约束**：定位不到唯一位置就说出来，请对方再给一个锚点。**不得挑一个最像的往下走。**

### momentum

- **判定**：三选一 ——（a）书是状态型的，读者在等一个不会来的情节；（b）书本身中段松，作者用氛围代因果；（c）书与读者当下不匹配。
- **做什么**：
  - (a) 重新定位核心，把「岔开的日常」翻译成「正在被摧毁/流逝的东西本身」；
  - (b) **直说书有问题**，不要为显得客观而把公认缺陷说成见仁见智；
  - (c) 给弃书许可。
- **交付物**：诊断结论 + 一个明确建议（继续 / 换媒介 / 弃）。
- **硬约束**：**必须保留弃书这个出口。** 没有它，这个模块只是变着法劝人读完。

### medium

- **判定**：这本书的线索靠什么标记？实词（换人、换地、新专名）在音频里活着；语法与排版（时态、人称、斜体、空行）在音频里死了。
- **附加判定**：走神后能否自己接回来？有因果链能，纯状态叙事不能。
- **做什么**：
  - 两条都输 → 建议换文本；
  - 输一条 → 混合方案（听为主 + 每章开头扫一眼第一句）；
  - 给实词层的替代抓手。
- **交付物**：能听 / 建议读 / 混合 + 这本书具体会丢什么。
- **备注**：同一逻辑适用于译本——靠时态分层的结构在无屈折语言里基本翻不过去。

### language（跨模块修饰层，不独立成卡点）

不单独路由，跨五个模块生效。触发条件：读者非母语 / 读的是非母语文本。

- **做什么**：任何卡点（难度 / 语境 / 迷失 / 动力 / 媒介）诊断完后，补一层判断——根是不是语言系统差异，而不是读者能力问题。
- **交付物**：预习词表 + 一条针对该语言对的读法提示。
- **措辞纪律（硬规则）**：说明这是语言系统差异，不是读者不够仔细。
