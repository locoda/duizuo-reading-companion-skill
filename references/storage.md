# 存储规格

只采用“一书一目录、三个 Markdown 文件”。不提前建立 work、edition、session、索引数据库或每次会话目录。

```text
reading/<书名>/
  book.md
  progress.md
  sealed.md
```

`sealed.md` 可在第一次需要封存观察时再创建。不得创建 `index.md` 或把电子本复制进书档；需要检索时，在原文件上按当前边界临时截断。

## 原则

- 目录名用通行书名；译本写字段，不拆目录。
- `book.md` 只放稳定、可复用、无读者痕迹的信息。
- `progress.md` 只放这次阅读的真实状态。
- `sealed.md` 只放因剧透边界暂时不能说的观察。
- conversation mode、即时深度、一次性情绪反应**不写入任何文件**。
- 本体只记本地路径；正文不复制、不上传、不外传。

## 旧档兼容

不要求立即迁移已有书档。读出现有字段，只有在用户报告真实变化时才补内容形态、状态或新进度字段；不整份重写，也不自动删除旧记录。旧档里的 conversation mode、`index.md` 或封存队列不得继续驱动路由或解封。

## `book.md`

```markdown
# 《书名》· 作者

- 内容形态：小说 / 短篇集 / 非虚构 / 叙事性非虚构
- 版本/译本：<未确认可写「未确认」>
- 别名：<原文名 / 其他译名 / 常见简称>
- 篇幅与形态：
- 附录：家谱 / 地图 / 注释 / 无

## 结构与读法
（只写不泄露未读内容的结构线索；说出口时仍受剧透权限约束）

## 语言难度

## 语境与典故

## 专名与译法

## 容易掉线的位置

## 内容形态备注
（短篇集：篇目是否独立、是否连作、共享人物或跨篇照应；只记录关系类型，不写未读情节）
（非虚构：论述型 / 传记 / 回忆录 / 调查 / 混合形态）

## 来源与核查备注
- 可核文本：已接入 / 读者确认没有整本 / 未确认
- 二手来源：
  - <来源标题 · 发布者/作者 · URL · 简介/书评/访谈/书目记录 · YYYY-MM-DD>
- 核查限制：<例如：无原文；具体引语、事件顺序或译法尚未核实>
```

版本或译本改变时，更新相应字段、专名与章节切分说明；不要新建第二个目录，也不要重写与译本无关的段落。

## `progress.md` 通用头部

前后材料仍沿用当前内容形态的进度字段，不新增文件或层级：把「前言」「导读」「后记」等明确写成当前阅读单元，并附单元内锚点。当前在前言时，正文篇目/章节仍按未读处理。允许语料是每轮临时核查结果，不持久化为新字段。

```markdown
# 《书名》· 阅读记录

- 阅读状态：未开始 / 在读 / 暂停 / 弃读 / 读完
- 媒介：读 / 听 / 混合
- 本体：<本地路径；没有则写「无」>
- 本书剧透覆盖：<仅在用户明确说“这本都可以剧透”时写 open；否则省略>
- 上次更新：YYYY-MM-DD
```

### 小说 / 线性叙事

```markdown
## 当前进度
- 当前锚点：<章/节 + 场景或人物行动；不要只写百分比>

## 锚点历史
- YYYY-MM-DD · <锚点>

## 已讨论问题与卡点
- YYYY-MM-DD · <difficulty/context/tracking/momentum/medium> · <一句事实性记录>
```

### 短篇集

```markdown
## 当前进度
- 当前篇目：<篇名；无则写「无」>
- 篇内锚点：<场景/段落；不只写百分比>

## 篇目状态
- <篇名> · 未读 / 在读 / 读完 / 跳过 · <可选锚点>

## 锚点历史
- YYYY-MM-DD · <篇名> · <状态或篇内锚点>

## 已讨论问题与卡点
- YYYY-MM-DD · <篇名> · <模块> · <一句事实性记录>
```

允许乱序。更新某篇时只改该篇；“读完一篇”不等于“读完整本”。未列出的篇目按未读处理，不推测。

### 非虚构

```markdown
## 当前进度
- 当前位置：<章 / 节>
- 当前主题：<概念、论证或案例>
- 已覆盖部分：<明确范围>

## 待澄清问题
- <问题>

## 进度历史
- YYYY-MM-DD · <位置> · <主题>

## 已讨论问题与卡点
- YYYY-MM-DD · <模块> · <一句事实性记录>
```

传记、回忆录等叙事性非虚构可在「当前位置」下追加场景锚点，以便守住事件剧透线。

## `sealed.md`

读中禁止读取。只有两种情况可整份打开：

1. `progress.md` 已明确为整本「读完」；
2. 用户明确把**整本**剧透权限改为 `open`。

用户只允许回答某一个具体问题，不等于允许打开整份 `sealed.md`。

```markdown
⚠️ 读中禁止读取。仅在整本读完或整本剧透权限明确为 open 时打开。

# 《书名》· 封存观察

## S1
- 封存于：YYYY-MM-DD
- 当时进度：<内容形态对应的锚点>
- 观察：<因剧透线没说的内容>
- 状态：封存中 / 已归还 YYYY-MM-DD
```

写入规则：只追加；写后不回读；不在 `progress.md` 留观察正文或暗示；不要告诉读者“有东西先不说”。

## 可分享性

| 文件 | 是否可分享 | 原因 |
|---|---|---|
| `book.md` | 可以 | 不含读者状态，且只收无剧透读法材料 |
| `progress.md` | 不可以 | 含个人阅读状态、本体路径与卡点 |
| `sealed.md` | 不可以 | 含尚未允许披露的内容 |
