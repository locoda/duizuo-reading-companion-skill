# 存储规格

`SKILL.md` 的「状态与存储」只留一张位置表：哪份状态存哪个文件、哪些能分享。本文件是格式规格——目录怎么命名、每个文件长什么样、读者档写在哪。

第一次创建某个文件时读本文件对应小节；之后的增量更新（改锚点、追加一条卡点记录）不必再读。

---

## 可分享性

`SKILL.md` 的位置表只给 ✅ / ❌，理由在这里：

| 文件 | 能分享吗 | 为什么 |
|---|---|---|
| `book.md` | 能 | 无读者痕迹，且采集时就把剧透挡在外面 |
| `index.md` | **不能** | 无读者痕迹，但骨架之外的索引内容有剧透面 |
| `progress.md` / `sealed.md` | 不能 | 私人阅读状态；`sealed.md` 更是压着没说的内容 |

---

**一书一目录。** 目录名用通行中文书名（无中译名则用原名），去掉书名号与路径非法字符，不转写拼音。

**译本不进目录名。** 叙事结构、掉线点、典故跨译本共享，只有专名译法和章节切分是译本相关的——按译本拆目录会大量重复。译本信息记在 `book.md` 的「版本/译本」和「译本差异」两处；读者换译本时改这两处，不新建目录。**但 `index.md` 要作废重建**——章节切分和行号跟译本走，换了译本，旧索引全部对不上。

**别名**记进 `book.md`，查档时一并匹配（原文书名、其他译名、常见简称）。

**位置**：`reading/` 放在当前工作目录；cwd 不在任何项目里时，兜底到宿主目录（如 `~/.workbuddy/reading/`、`~/.claude/reading/`）。

### book.md

```markdown
# 《书名》· 作者

- 版本/译本：<读者手上的那个；未确认就写「未确认」>
- 别名：<原文书名 / 其他译名 / 常见简称，查档时一并匹配>
- 篇幅与形态：
- 附录：家谱 / 地图 / 注释 / 无

## 叙事结构
（有几条线、每条线怎么被认出来。跨译本共享）

## 语言难度

## 语境与典故
（书名与题记的典故写这里。跨译本共享）

## 需要提前认识的专名
（**译本相关**——换译本要重采）

## 最可能掉线的位置
（跨译本共享）

## 译本差异
（只在读者换译本、或档案来自他人时展开：专名译法对照、章节切分是否一致、有无删节）

## 采集备注
（哪些没查到、哪些存疑）
```

### index.md

只在接了本体之后才有。**按锚点截断读取**——锚点之后的行不进上下文。

```markdown
⚠️ 按锚点截断读取。锚点之后的行不得进入上下文。

# 《书名》· 文本索引

- 骨架建到：<全书 / 第 N 章 / 未建，用到哪章现截哪章>
- 索引内容建到：<锚点>

## 骨架
（章号 + 起止位置。**不含章节标题**——标题会剧透）
- ch01 · L1–L340
- ch02 · L341–L689

## 已读范围的索引
（只做到锚点为止，读者推进时增量补）
- ch01 · 标题「<标题>」 · 首句「<首句>」 · 首次出现：<专名>
```

### sealed.md

**读中禁止整份读取。** 只有两种打开方式：封存队列判定某条到期时按 id 定点取那一条，或 debrief 时整份归还。首行的禁读声明是写给下一次会话的自己看的，不要删。

```markdown
⚠️ 读中禁止整份读取。仅在封存队列判定到期时按 id 定点取用，或 debrief 时整份归还。

# 《书名》· 封存观察

## S1
- 封存于：YYYY-MM-DD · 当时锚点 <锚点>
- 解封条件：anchor ≥ <锚点>
- 观察：<当时因剧透线没说的那句>
```

### 读者档

记录**跨书的稳定特质**。媒介、进度锚点等当本书的状态不写这里。

| 字段 | 来源 | 影响 |
|---|---|---|
| 剧透尺度 | 给默认值让其反对 | L1 剧透线 |
| 阅读语言与母语关系 | 观察 | 是否启用 language 修饰层 |
| **已知卡点模式** | 每本书 debrief 时从「卡点记录」回写 | L0 建档后、prep 阶段提前预警 |
| 解释颗粒度 | 观察反应 | 回答的技术密度 |
| 读完想做什么 | 观察 | debrief 落点 |

**「已知卡点模式」是核心字段。** 同一个人反复栽在同一类书上，攒够两三次即可在 prep 阶段拦截。这是本 skill 随使用变强的唯一机制。

**存储**：写入宿主 agent 的用户级持久记忆，小节名「Reading Profile」。具体文件由宿主决定——如 Claude Code 的 `~/.claude/CLAUDE.md`、WorkBuddy 的 `~/.workbuddy/MEMORY.md`，其余宿主同理。

- 首次使用：给剧透尺度默认值（`strict`），建立该小节骨架。
- 同类型卡点攒够两三次才固化为模式，单次不写入。
- 推断字段（阅读语言与母语关系、解释颗粒度、读完想做什么）：先向读者确认，再写入。
- 读取时机：L0 建档后、prep 阶段先读该小节，命中已知卡点模式则提前预警。
- 无持久记忆机制时：不存，每次重问必问项，不假装记得。

**覆盖优先级**：当次指令 > `progress.md` 的本书覆盖 > 读者档默认值。「这本我不介意剧透」只对本书生效，写进 `progress.md`；除非明说「以后都这样」，才改读者档。
