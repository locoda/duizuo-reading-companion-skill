# 适配判断（fit）

回答两个问题：**这本我读得懂吗**、**这本我会喜欢吗**。只在读者主动问时加载、主动问时给；读者没问，不主动给判断、不推书。

## 前提：读者档案

判断的唯一读者侧依据是 `reading/profile.md`（规格见 `storage.md` 的 `profile.md` 一节）。

档案不存在，或读完/弃读记录少于 3 本时：

- 明说档案还不够判断，只给不依赖档案的信息（出版社与书目信息、公开口碑），并说明判断会从陪读积累里长出来。
- 不许拿对读者的一般印象（"你平时看文学小说多"）冒充档案判断。一般印象不是记录。

## 目标书信息

对目标书只用公开信息：出版社与书目信息、公开书评与介绍、已公开的目录与前后材料。用二手来源时，第一句话声明来源与置信度（同 SKILL.md §2 的来源声明）。

- 不打开、不搜索目标书正文来做判断；判断不需要、也不允许碰未读内容。
- 做判断不改变目标书的任何剧透权限。读者还没决定读时，不为目标书建档；决定读了，建档照常走 §5 的 CHECKPOINT。

## 判断一：读不读得懂 → 预期卡点图

不给"能 / 不能"的判决，给卡点图：

1. 对照档案里的难度证据：读完过的同类高难度作品、弃读与暂停的原因类型、历史卡点类型（难度 / 背景 / 跟丢 / 语言 / 媒介，分类见 `modules.md`）。
2. 列出预计卡点：类型 + 可能出现的阶段 + 对策（换媒介、先备哪块背景、这类结构能否跳读、听读会不会丢关键信息）。
3. 给一句总体定位：以读完过的 X 为锚，这本在句法 / 概念 / 信息量 / 语言上是同档、高一档还是低一档。
4. 档案里没有可比维度的，明说"这一项没有依据"，不猜。

## 判断二：会不会喜欢 → 相似性论证

1. 从档案里挑 2–3 本读者有明确反应的书（有明确喜欢和明确不喜欢的各一本优先），逐本给出像 / 不像的点。维度只能取档案里记录过的反应维度——结构、叙述视角、节奏、题材、语言质地等她实际评论过的——不许凭作品名气、类型标签或"大家都说好"推断。
2. 结论只用三档：**大概率合** / **可能合，但有一个风险点** / **大概率不合**。风险点必须具体，能指回档案里的某本书或某句原话（"结尾的收法像你弃掉的 X"）。
3. 不给百分比、星数或任何伪精确量化。
4. 若目标书有一点与档案倾向相反、但公开口碑指向读者在意的价值，如实列为"不确定因素"，不抹平，也不因此翻转结论。

## 共同纪律

- 两个判断都要能指回档案的具体条目；指不回去的依据不许写。
- 历次判断结论不落盘。档案只沉淀结果与读者的真实反应（读完 / 弃读 / 她读后说的话），判断对不对由后续结果自然校正，不靠回改记录。
- 判断之后读者决定不读，不劝、不挽留；决定读，回到正常陪读流程。
