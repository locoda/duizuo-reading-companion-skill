# 对坐（reading-companion）

> *「读到哪，聊到哪，一个字都不多说。」*

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE) ![Agent Skills](https://img.shields.io/badge/Agent%20Skills-兼容-green)

**阅读陪伴 · 陪一个人读完一本虚构长篇。开读前教他怎么读，开读后只聊他读到的部分，一个字都不剧透。**

裸模型也能分析一本书——但它会顺手做两件事：**剧透**、**编造情节**。你问「奥德赛在喀耳刻岛上待多久」，它张口就是一个答案，可你才读到第三卷。剧透不可撤销，编造的情节会被你当事实继续推理。

对坐把「不剧透」做成硬约束：**你读到哪，它只聊到哪。**

```
npx skills add locoda/reading-companion-skill
```

跨 agent 通用——Claude Code、Cursor、Codex、WorkBuddy 都能装。

## 看效果对比

同样一个问题：「**奥德赛在喀耳刻岛上待了多久？**」（假定你才读到第三卷）

**裸模型：张口就来，不问进度**

> 「他在喀耳刻那里待了整整一年。」——答得又快又完整，但你还没读到第十卷，这一句就把后面的剧情透干净了。

**对坐：先卡住，再给可核的路径**

> **读者**：奥德赛在喀耳刻岛上待了多久？
>
> **对坐**：这个我得先卡一下。喀耳刻（Circe）的情节在第十卷，属于具体情节，而我不知道你读到哪了。如果你还没读到第十卷，我现在说出来就是剧透。
>
> 你读到第几卷了？或者用内容描述一下——比如「已经到 Odysseus 下冥府问 Teiresias」，还是「还在 Telemachus 寻父那段」。
>
> 如果你已经读过 Circe 那段，我直接告诉你，还能回原文给你核字句；如果还没读到，我先不说，你读到第十卷再来问。

差距：**裸模型给你一个可能剧透的答案；对坐先确认你没被剧透，再决定答不答。**

## 装上就能用

**无前置依赖**，直接装：

```
npx skills add locoda/reading-companion-skill
```

或手动复制整个目录到 agent 的 skills 目录（Claude Code 的 `~/.claude/skills/`、Codex 的 `~/.codex/skills/`）。

跑起来：

```
"我想读《尤利西斯》"          → prep：问媒介，给抓手清单
"第三章完全读不懂"            → assist：分诊 difficulty + context
"跟丢了，这是谁"             → assist：tracking 定位
"好无聊，要不要弃"           → assist：momentum 三选一，弃书是可给出的答案
"X 里那个人为什么突然走了"    → 无原文 → 给可核路径，不编答案
"刚读完，想聊两句"           → debrief：先问后写
```

模糊的需求也认：「读不进去」「这书到底写的啥」「我是不是该弃了」。

## 三阶段

| 阶段 | 干什么 | 触发话术 |
|---|---|---|
| **prep** | 开读前，交付「这本书怎么读」的抓手清单——几条线怎么认、要认识的专名、书名典故、最可能掉线的地方 | 「我想读 X」「要不要读 X」 |
| **assist** | 读中，分诊五种卡点（难度 / 语境 / 迷失 / 动力 / 媒介），各走各的解法 | 「读不懂」「这是谁」「跟丢了」「要不要弃」 |
| **debrief** | 读完后，先问具体到这本书的问题，再归还读中压着的结构观察，最后落成几句话 | 「读完了」「刚看完 X」 |

开读前的抓手清单长这样（《奥德赛》为例）：

> **几条线**：前四卷是儿子线——Telemachus 在 Ithaca 被求婚者骚扰，出门打听父亲下落；第五卷起是父亲线——Odysseus 从 Calypso 处脱身、漂流到 Phaeacia；第十三卷起两线合流回 Ithaca。认线看一卷开头的人名和场景。
>
> **专名**：这译本用拉丁名，和常见中文译本的希腊名对不上——Ulysses=奥德修斯、Jove=宙斯、Pallas/Minerva=雅典娜、Mercury=赫尔墨斯。
>
> **最可能掉线的地方**：第九到十二卷。Odysseus 在 Phaeacia 宴会上自述十年漂泊，时间线突然跳回过去，是「故事里的故事」，最容易跟丢。

## 核心纪律

两条线，一条都不能破：

- **情节受进度限制**：你读到哪，只聊到哪。手上有原文，逐字核；没原文，不编情节，只给可核的路径。
- **读法不受进度限制**：开读前把「怎么读」讲全——结构、专名、典故。这些不剧透，却决定你能读进去多少。

一条硬规则：**没有原文时，具体情节和事件顺序一律不答**，只给「去哪核、核什么」的路径。追着问「你就大概说说」也不让步——编造的答案会被你当事实继续推理。
