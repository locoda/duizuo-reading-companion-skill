# 对坐 / Duizuo Reading Companion

> 读到哪，聊到哪。一个字都不多说。卡住的地方，帮你照亮，让你自己决定怎么读下去。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE) ![Agent Skills](https://img.shields.io/badge/Agent%20Skills-compatible-green)

对坐是一个陪你把书读完的 skill，不替你读，不剧透，只在你卡住、想聊、想弄明白的时候，陪在旁边。

兼容 Claude Code / Cursor / Codex 等支持 Agent Skills 的工具。

## 第三章完全看不懂，又不想被剧透的时候

**比如这样：** 读《尤利西斯》第三章，海滩那段完全跟丢了。句子碎得像潮水，你怀疑是不是自己漏看了什么，想放弃，又怕一问就被剧透后十章。

> 「第三章完全读不懂，是我漏了什么吗？」

直接问通用 AI，往往得到一段漂亮但越过你进度的总结——问题好像解决了，但接下来十章的发现感也没了。

**对坐会这样回：**

> 你没有漏看。这段的「碎」就是写出来的效果——这一章叙述从旁观切到了斯蒂芬的内在独白，时间还在海滩上午，没有跳到后面。
>
> 你可以先看每段开头的人称和感官词（「他看见」「他想起」），它们能帮你判断现在是谁在看，而不是发生了什么新事。你读到的第四章开头那句，也还在同一个上午。
>
> 要不要我按你已读的前三章，把海滩这一场的人物和视角帮你理一下，不带后面的？

**然后你就可以：**

- 判断这段难是文本本身的设计，不是你的问题，决定继续读
- 用「人称 + 感官词」这个不剧透的小方法，自己去试下一页
- 随时说「别分析了，陪我骂两句」，对坐就会停下来

力量回到你手里：不是被告知结局，而是被还回继续读的工具。

## 它是怎么陪你的

### 只聊你已经读到的

默认不碰没读的部分。有电子书时，会先确认你读到哪，再在那个范围内找。没有电子书时，会告诉你去哪儿核、怎么核，不拿模型记忆来补。

你开放了后面的目录，不等于你读完了；你读完了 A，不等于可以聊 B。找不到原文，就说「你读到的部分里没有」，不编。

地点、意象、结构、论点——这些也可能剧透，一样守着。

### 每一次都重新听你想怎么聊

对坐不给你贴标签。这次想聊剧情，下次想聊写法，它都重新听。

- 聊剧情：谁、顺序、因果
- 聊感受：被触动、被气到、被震住
- 聊写法：语言、视角、节奏、意象
- 聊理解：主题、象征、不同读法
- 聊评价：好不好、值不值得
- 只想有人陪着：一起笑、一起叹气

你说「别分析」就停在安慰，说「再深一点」再展开。非虚构不走剧情那套，会按观点、证据、怎么用的来聊。

### 记得住，但不替你做决定

一本书最多记三份小文件，都在 `reading/<书名>/` 里，存的是上次聊到哪、是什么版本、卡过哪儿。

每次重开，它会先读档，然后跟你确认：「上次你在第三章海滩，之后又读了吗？」——记的是上次在哪，不是你现在在哪。

如果你在听书，或者工具本身记不住文件，它会明说，不会假装记得。

卡住也有不同原因：看不懂、缺背景、跟丢人、读不动了、听不清、语言本身。对坐会先分清楚是哪种，再决定怎么陪。

## 还有哪些没做好

- 不同版本、删节本、重排本之间，定位还是有点脆弱，找不到时只能先不碰原文
- 为了不「为分类而翻书」，内容形态没确认时会先写「未确认」，不会去偷看后面的来猜
- 整本的封存笔记是整份打开的，还做不到只解开其中一章
- 听书的进度现在还得靠你自己说，没法从音频自动对上文字
- 私有电子书只记本地路径和指纹，不上传，不外传

## 以后想做成什么样

- 更稳的前言、导读、后记识别，不同译本之间能对上
- 每本书的高质量收尾问题库，而不是固定问卷
- 可选的、完全基于已确认进度的阅读节奏小图，不推断没读的
- 长篇非虚构的观点和证据缺口提示，还是守着已读边界

以前的问题会放到 CHANGELOG / Issues 里，不会一直堆在这里。
