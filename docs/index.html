对坐

读到哪，聊到哪，
一个字都不多说。

读书最怕两件事。
一件，是有人替你翻到还没读的页，把结局说漏了嘴。
一件，是有人装作读过，随口编个情节给你。

对坐记得你的阅读位置，也判断你此刻想怎么聊。它陪读，不替读。

对坐

没读到，不提前说；读到了，也只说能从原文确认的。

界

它把「怎么读」和「发生了什么」分开

这个区分是整件事的地基。读法可以提前给；情节只能停在你确认读过的地方。

读法，先告诉你怎么看

人物多，就讲怎么认；时间层乱，就讲怎么看切换。只说靠什么辨认，不顺手告诉你后来发生什么。

情节，只聊你读过的

能看到书，就只在你已经读过的部分找答案；看不到书，就请你贴一小段，或者告诉你该回哪里找。不拿模糊记忆凑答案。

聊

它先听你这一刻想怎么聊

同一句「我受不了了」，可能是在问人物动机，也可能只是想有人一起叹气。对坐不预设你是什么读者，只听这一刻你需要什么。

梳理情节

把已经发生的、人物自己说的、可以推断的和仍不确定的分开。

接住情绪

先回应你的感受，再陪你看这本书为什么会让人这样难过、愤怒或震动。

细看写法

不只说「写得美」，而是一起看视角、节奏、意象和语言做出了什么。

讨论读法

陪你展开一种理解，也指出它的证据、漏洞和别的可能。

认真评价

不只问喜不喜欢，也看它想做什么、做成了多少、代价是什么。

只是陪着

你只想笑、骂、叹气时，它不会硬把气氛升级成分析课。

你说「别分析」，它就停在接住；你说「别顺着我」，它才拿出反证和真正不同的读法。

导

开读前，只讲怎么认，不讲后来发生什么

《奥德赛》为例。导读给的是导航，不是预告片。

认线方法
先看每卷开头的人名、地点和叙述人称。它们能帮你判断当前是哪条叙事线，但不提前说这些线后来如何汇合。
专名
这译本用拉丁名，和常见中文译本的希腊名对不上——Ulysses＝奥德修斯、Jove＝宙斯、Pallas / Minerva＝雅典娜、Mercury＝赫尔墨斯。
掉线提醒
叙述者和时间层切换时，先确认现在是谁在讲、地点是否变化。遇到较长的第一人称回顾，把它当作嵌套叙事。
记

它记得你读到哪，也记得什么现在不能说

一本书读上几周，你不用每次都重新介绍。它记得你在读哪个版本、是在看还是在听、上次读到哪里，也记得你曾经在哪儿卡住。

你带着问题来，它先回答，不拿一串问题挡在前面。下次回来，它会把旧位置当作「上次读到这里」，先确认你后来有没有继续读。

有些观察现在说就是剧透，它会先压住，也不会用「我有件事先不说」来暗示你。等整本读完，或你明确说这本都可以剧透，再在相关话题里告诉你。
