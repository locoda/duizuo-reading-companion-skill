读书最怕两件事。
一件，是有人替你翻到还没读的页，把结局说漏了嘴。
一件，是有人装作读过，随口编个情节给你。

这两件，AI 都爱干——尤其没人管着它的时候。

对坐

一个张口就答，一个先问你会不会被剧透。

界

它把「怎么读」和「发生了什么」分开

这个区分是整件事的地基。裸模型给得出前一半，但会顺手把后一半一起给了。

读法，不受进度管

开读前把「怎么读」讲全——几条线怎么认、要提前认识的专名、书名典故、最容易掉线的地方。这些不剧透，却决定你能读进多少。

情节，受进度管

你读到哪，聊到哪。有原文，逐字核；没原文，不编，只给「去哪核、核什么」。追着问「你就大概说说」也不让步——编出来的答案，你会当真的。

导

开读前，它先给你一份导读

《奥德赛》为例。通篇没有一句剧情，但读起来会不一样。

几条线
前四卷是儿子线——Telemachus 在 Ithaca 被求婚者骚扰，出门打听父亲下落；第五卷起是父亲线——Odysseus 从 Calypso 处脱身、漂流到 Phaeacia；第十三卷起两线合流回 Ithaca。认线看一卷开头的人名和场景。
专名
这译本用拉丁名，和常见中文译本的希腊名对不上——Ulysses＝奥德修斯、Jove＝宙斯、Pallas / Minerva＝雅典娜、Mercury＝赫尔墨斯。
最容易掉线的地方
第九到十二卷。Odysseus 在 Phaeacia 宴会上自述十年漂泊，时间线突然跳回过去，是「故事里的故事」，最容易跟丢。
记

一本书要读三周，你不该自我介绍二十遍

书第一次进对话时，它先把这本书认清楚：哪个版本、哪个译本、你是在读还是在听。这些不是细节——删节本少掉的章会让进度对不上，不同译本人名译法不同，认人就会认错。

认完摆出来给你核，你点头它才记下。之后它记得住你读到哪、在读哪个译本、之前在哪儿卡过。

每次重开，它先看一眼记录，再问一句「上次你在第三章海滩，之后又读了吗？」——记下的是「上次说话时你在哪」，不是「你现在在哪」。你会在它不在场的时候继续读，这中间隔着一条剧透线。
